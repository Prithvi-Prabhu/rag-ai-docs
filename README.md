# Smart Documentation Assistant (RAG)

A Retrieval-Augmented Generation (RAG) system that ingests technical documentation from the web and enables question answering.

## Features
- Web scraping of documentation
- Semantic search using FAISS
- Local embeddings (HuggingFace)
- LLM-based answers
- Source attribution

## Tech Stack
- Python
- LangChain
- FAISS
- HuggingFace Embeddings
- (Optional) OpenAI / Ollama

python -m app.main
